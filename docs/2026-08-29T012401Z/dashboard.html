How to read this report

The dashboard distinguishes sustainable rankings from peak observations.

Sustainable throughput

Only a concurrency level whose RPM spread stays within the configured stability threshold can be ranked.

Peak observed throughput

The highest median RPM seen during this run. It remains visible even when variance prevents a sustainable rank.

Latency percentiles

p50, p95, and p99 cover successful validated responses. Lower values mean requests complete faster.

Error rate

Failed transfers, timeouts, invalid statuses, and rejected response bodies count against the measured phase.

Remote telemetry

PHP peak memory, execution time, and included files are emitted by each target and parsed separately from client latency.

Fairness controls

Targets rotate execution order between repetitions and must pass response and telemetry validation before measurement.

Target-server environment

Actual PHP and OPcache settings from the web runtime that received benchmark requests.

Load-generator and benchmark configuration

CLI runtime values come from the load generator; per-target variations remain under Run details.
